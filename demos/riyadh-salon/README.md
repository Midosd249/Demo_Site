# LUMÉRA — Beauty Atelier

Premium ladies-salon website demo for the Riyadh field-sales portfolio.

## What it sells

This demo sells the **website layer**:

- Premium brand presentation
- Service discovery with category filtering
- Starting prices and estimated durations
- Occasion / bridal package positioning
- WhatsApp booking with contextual service details
- Phone and map conversion paths
- Mobile sticky booking navigation
- Arabic-first RTL with an English direction toggle
- Responsive desktop/tablet/mobile layouts

It intentionally contains **no digital-menu functionality**. Digital menus belong to the separate menu repository.

## Visual direction

LUMÉRA uses a warm editorial world built around:

- Ivory / espresso / muted rose / olive
- Playfair Display + IBM Plex Sans Arabic + DM Sans
- Asymmetric photography-led layouts
- Large serif typography
- Quiet micro-interactions
- Strong whitespace
- One dominant conversion path

The goal is to make a salon owner see a finished brand experience rather than another generic template.

## Demo policy

All business details are fictional. Replace:

- phone
- address
- map destination
- service pricing
- imagery
- operating hours
- booking provider
- package details

before production use.

Unsplash imagery is used as replaceable demo imagery only. Verify licensing and replace with client-owned/licensed assets for production.

## Sales sequence

1. Open the hero on mobile.
2. Show the service filter.
3. Tap a service and demonstrate contextual booking.
4. Jump to the occasion section.
5. Finish on the booking panel.
6. Position the site as the layer around the client's existing operational tools, not as a replacement for the separate menu product.
