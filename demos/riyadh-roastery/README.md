# مَطْلَع — Roastery Demo

نموذج تجريبي لمحمصة قهوة افتراضية في الرياض، صُمّم للعرض الميداني لأصحاب المحامص.

## الفكرة

**سجل التحميص كقطعة تحريرية**: بدل افتتاحية متجر تقليدية، يظهر المنتج بجانب ورقة تحميص، ثم تتحول رحلة الصفحة من الحبة إلى المحصول إلى قرار التحضير.

## Forner — Style Reference

تمت قراءة المرجع كاملًا قبل التنفيذ. تم الاحتفاظ بالمبادئ التالية:

- Bone / roast palette: #faf5eb و #484036 و #ecece4 و #cacab0 و #666e72.
- الأسطح المسطحة والحدود الرفيعة والزوايا الحادة.
- الإيقاع التحريري والمساحات الصامتة.
- serif italic كتعليق نادر، لا كنص أساسي.
- التراتبية بالحجم والفراغ والتكوين، مع تكييفها للقراءة العربية.

تم رفض نسخ تخطيط Forner أو نصوصه أو صوره أو هويته. التكوين هنا خاص بمحمصة: منتج + سجل تحميص + اختيار منشأ + طقوس تحضير.

## الأصول

الأصول داخل assets/ هي SVG مرسومة خصيصًا لهذا النموذج، لتجنب روابط صور غير موثوقة ولإبقاء العرض متسقًا. لا تمثل منتجات حقيقية.

## التفاعل

- اختيار 3 محاصيل يغيّر المواصفات والنص.
- اختيار طريقة التحضير يغيّر نقطة البداية.
- زر الاستفسار ينسخ رسالة تجريبية فقط، ولا يوهم بوجود متجر أو دفع أو رقم واتساب.
- دعم prefers-reduced-motion.
- breakpoint أساسي عند 1100px لإعادة تركيب الصفحة للهواتف والأجهزة اللوحية.

## الحالة التجارية

الموقع DEMO / noindex,nofollow. الأسعار والمنتجات افتراضية للعرض فقط، ولا توجد شهادات أو مراجعات أو فروع أو بيانات تشغيلية مثبتة.

قبل تحويله لعميل حقيقي: استبدال الهوية، المنتجات، الأسعار، بيانات المنشأ، الصور/الأصول، بيانات التواصل، سياسة المتجر، ووجهة الطلب/الدفع بعد التحقق.
