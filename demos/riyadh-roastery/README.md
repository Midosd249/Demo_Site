# NŪR / نور — Specialty Coffee Demo

First field-sales demo for the Riyadh website portfolio.

## What it demonstrates

- Arabic-first RTL hospitality design.
- Premium editorial visual direction.
- Mobile-first digital menu.
- Category filtering.
- Product detail sheet.
- WhatsApp and directions conversion actions.
- Sticky mobile conversion bar.
- Reduced-motion support.
- Easy reskinning for a real restaurant or cafe.

## Demo status

This is fictional DEMO content. It is not a real business and does not claim real ratings, locations, reviews, sales, or operating hours.

Before client launch, replace:

- Brand name and logo.
- Menu data and prices.
- Photography.
- Branch address and map.
- WhatsApp destination.
- Operating hours.
- Legal/business details.
- SEO metadata.
- Structured data.

## Asset references

Demo photography uses Unsplash image URLs. The image search was used only to select replaceable hospitality imagery. For production, prefer client-provided photography or assets with a documented commercial license.

Open-source implementation research included MIT-licensed Next.js/shadcn landing references, but this demo is implemented in the repository's existing static/vanilla architecture rather than copied from those projects.

## Commercial handoff

The strongest sales sequence is:

1. Hero.
2. Open menu.
3. Filter.
4. Open an item.
5. WhatsApp.
6. Visit/location.
7. Explain that the same system can power the client's QR menu and full website.
